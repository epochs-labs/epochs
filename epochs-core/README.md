# epochs-core

Content-addressed Merkle-DAG storage: append-only CAS, persistent HAMT documents,
commits with optional `index_roots`, and a disk-backed `DiskStore`.

Part of the [epochs](https://github.com/epochs-labs/epochs) workspace.

**Stability:** 0.1.x — APIs may change without a major bump until 1.0.
